# Toolbox logo sources

The SVGs retain their source colors and shapes.

- Python, FastAPI, HTML5, CSS3, and JavaScript: original variants from [Devicon](https://github.com/devicons/devicon/tree/master/icons). The included `DEVICON-LICENSE` preserves the project's MIT license notice. Brand marks belong to their respective owners.
- BigQuery: `bigquery/bigquery.svg` from Google's [official legacy console icon library](https://cloud.google.com/icons), downloaded from https://services.google.com/fh/files/misc/google-cloud-legacy-icons.zip.
- HTML5 logo credit: [W3C](https://www.w3.org/html/logo/), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
