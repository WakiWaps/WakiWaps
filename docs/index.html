03 — HOW I THINK

The workflow
comes first.

Good tools start with a clear understanding of what people need to get done.

01 / UNDERSTAND

Find the friction.

Map the task, the people involved, and the point where things get difficult.

02 / BUILD

Make it usable.

Connect a clear interface with the logic and data the workflow needs.

03 / VERIFY

Check the edges.

Look at input errors, expected behavior, and what happens when a step fails.

04 / HAND OVER

Keep it clear.

Document decisions and explain the next step so the work can move forward.
